## 🚀 Featured Projects

### ⭐ [Unsupervised ML Explorer](https://github.com/lisaluo88/Luo-Data-Science-Portfolio/tree/main/MLUnsupervisedApp)
**[🔗 Launch Live App](https://luo-unsupervised-ml.streamlit.app)**

An interactive Streamlit app for exploring **K-Means clustering, Hierarchical clustering, and PCA** on any tabular dataset. Users tune hyperparameters with sliders and watch elbow curves, dendrograms, and scree plots respond in real time.

`Streamlit` `scikit-learn` `scipy` `matplotlib` · *capstone project*

---

### [ML Explorer — Supervised Learning](https://github.com/lisaluo88/Luo-Data-Science-Portfolio/tree/main/MLStreamlitApp)
**[🔗 Launch Live App](https://luo-data-science-portfolio-99.streamlit.app/)**

A no-code interface for training and evaluating **Logistic Regression, Decision Trees, and K-Nearest Neighbors** classifiers. Confusion matrix heatmaps, ROC curves, and feature importance charts update live as parameters change.

`Streamlit` `scikit-learn` `seaborn` · *end-to-end ML application*

---

### [Tidy Data — 2008 Olympics Medalists](https://github.com/lisaluo88/Luo-Data-Science-Portfolio/tree/main/TidyData-Project)

Reshaped a wide, messy Olympics dataset (variables encoded in column headers) into a clean long-format DataFrame using **Hadley Wickham's tidy data principles**, then explored medal distributions through pivot tables and Seaborn visualizations.

`pandas` `seaborn` `Jupyter` · *data cleaning & analysis*

---

### [Penguins Insights Dashboard](https://github.com/lisaluo88/Luo-Data-Science-Portfolio/tree/main/basic_streamlit_app)

A multi-page Streamlit dashboard for exploring physical traits across Adelie, Chinstrap, and Gentoo penguin species, with a global species filter that flows through every page.

`Streamlit` `pandas` `matplotlib` · *interactive UI prototype*
